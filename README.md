# Expense Tracker CLI

## Project Overview

Expense Tracker CLI is a Python-based command-line application that helps users record and manage their daily expenses. The application stores expense data in a JSON file, allowing users to maintain records even after closing the program.

## Features

* Add new expenses
* View all recorded expenses
* Delete unwanted expenses
* Calculate total spending
* Store data using JSON
* Simple command-line interface
* Easy to use and maintain

## Technologies Used

* Python 3
* JSON
* File Handling
* Command Line Interface (CLI)

## How to Run the Project

1. Open the project folder in VS Code.
2. Open Terminal.
3. Run the following command:

python expense_tracker.py

## Menu Options

1. Add Expense
2. View Expenses
3. Delete Expense
4. Total Spending
5. Exit
